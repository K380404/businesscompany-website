# BusinessCompany SEO Starter

This project is a lightweight SEO-ready business website starter.

## Included
- Semantic HTML structure
- Meta tags for SEO and social sharing
- Structured data for LocalBusiness
- Sitemap and robots configuration
- Web app manifest and favicon

## Preview locally
Open the folder in a browser, or run:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000

## Customize before launch
- Update the business name, contact details, and address in `index.html`
- Replace the placeholder domain in `sitemap.xml` and `canonical` URLs
- Add your real logo and social images
- Submit `sitemap.xml` to Google Search Console and Bing Webmaster Tools
